# Code of Conduct

Brilliant UI follows the Contributor Covenant Code of Conduct, version 2.1.

Be respectful, assume good intent, and keep technical disagreement focused on the work. Harassment,
abuse, discriminatory language, and sustained disruption are not acceptable in project spaces.

Report conduct concerns to the maintainers listed in the repository security policy. Maintainers may
remove comments, close issues, or restrict participation to protect the project community.
